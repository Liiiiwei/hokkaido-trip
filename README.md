# 行程共編網站

同行的人用同一個連結看行程、一起排行程。網站放 GitHub Pages，行程資料存在另一個私人儲存庫的 `trip.json`，不需要資料庫。

## 怎麼運作

- 分享連結長這樣：`https://<帳號>.github.io/hokkaido-trip/#k=<權杖>`。
- 權杖是只對資料儲存庫有 Contents 讀寫權限的細部權限權杖。
- 第一次用完整連結開啟後，權杖存在裝置上，網址列上的權杖會被拿掉。
- 頁面每 15 秒重抓一次資料；存檔時若有別人先存，會重抓再存一次。

## 本機執行

1. 建立 `.env.local`，內容一行 `TRIP_TOKEN=<權杖>`（只給測試用，不會進版控）。
2. `npm install`
3. `npm run dev`，開 `http://localhost:3210/#k=<權杖>`

## 測試

- `npm test`：單元測試
- `npm run e2e`：兩個視窗的同步驗收（會讀寫真的資料檔，測試資料跑完自動清掉）

## 換鑰匙

到 GitHub 把舊權杖作廢、建立新的，再把新的分享連結發給大家。
