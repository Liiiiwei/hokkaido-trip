# 行程共編網站

同行的人用同一個連結看行程、一起排行程。網站放 GitHub Pages，行程資料存在另一個私人儲存庫的 `trip.json`，不需要資料庫。

## 怎麼運作

- 分享連結長這樣：`https://<帳號>.github.io/hokkaido-trip/#k=<權杖>`。
- 權杖是只對資料儲存庫有 Contents 讀寫權限的細部權限權杖。
- 第一次用完整連結開啟後，權杖存在裝置上，網址列上的權杖會被拿掉。
- 也可以不帶權杖直接開網址，輸入密語進入：權杖用密語加密後放在 `public/door.json`（`lib/door.ts`），輸入對的密語才解得開，解開後一樣存在裝置上。加密檔是公開的，密語有多難猜，權杖就有多安全。
- 頁面每 15 秒重抓一次資料；存檔時若有別人先存，會重抓再存一次。

## 手機上的操作

- 卡片往左滑：露出編輯與刪除。卡片以外的地方左右滑：換到前一天或後一天。
- 沒填時間、或開始時間相同的行程，卡片上有握把，長按卡片或拖握把可以調先後（存在行程的 `order` 欄位）。開始時間不同的行程先後由時間決定。
- 旅程當天打開會停在今天，並捲到下一站。
- 可以加到手機主畫面。主畫面版本第一次開啟要再輸入一次密語（它和瀏覽器不共用儲存空間）。
- 沒有網路時打得開，看到的是上次讀到的行程；要修改得等網路回來。
- 配色跟著手機的淺色或深色設定。

## 離線是怎麼做的

- `public/sw.js` 把頁面與程式檔存在手機裡；只在正式建置啟用，`npm run dev` 不會啟用。
- 行程資料另外存一份在 `localStorage`（`lib/offline.ts`），開啟時先顯示這一份再抓最新的。
- 出新版時頁面會自動重新整理，舊版的程式檔在那時候清掉。

## 本機執行

1. 建立 `.env.local`，內容一行 `TRIP_TOKEN=<權杖>`（只給測試用，不會進版控）。
2. `npm install`
3. `npm run dev`，開 `http://localhost:3210/#k=<權杖>`

## 測試

- `npm test`：單元測試
- `npm run e2e`：兩個視窗的同步驗收，加上畫面與手機手勢的驗收（手勢用假的 GitHub 回應，不連線）。讀寫的是資料儲存庫裡另一個檔案 `trip.e2e.json`，不會動到正式的 `trip.json`

## 換鑰匙

到 GitHub 把舊權杖作廢、建立新的，更新 `.env.local`，重跑 `node scripts/seal-door.mts <密語>` 後重新發佈。大家再輸入一次密語就進得來，不用重發連結。

只換密語也是跑同一個指令。換密語擋不住已經解開過的人，要一起換權杖才算數。
